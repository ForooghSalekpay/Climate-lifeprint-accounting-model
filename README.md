# Climate lifeprint accounting model

This repository contains the Python code used for the accounting model
and sensitivity analyses presented in the paper:

"From Carbon Footprint to Climate Lifeprint: Comparison and accounting
model for ultra-rich social influencers"

## Files

- Climate lifeprint model.ipynb: complete Jupyter notebook containing
  scenario calculations and sensitivity analyses.
-  Climate lifeprint model - 2.py: Python script version of the model.

## Model structure

The model contains six scenarios:

1. Societal carbon footprint
2. Reference societal climate lifeprint
3. Climate-advocate celebrity
4. EV-industry innovator
5. Climate-skeptical politician
6. Joint EV-industry innovator and climate-skeptical politician


## Software

Python 3.x

Main packages:
- NumPy
- pandas
- matplotlib
